# Standard

Up: [[MOC|Vault Root]]

The only documentation standard in this vault. Every document obeys it.

## Every folder carries a MOC

A MOC is the folder's front door and its index.

It takes its folder's name, without the number. `0013-thinking/` holds
`thinking-MOC.md`. The vault root is `MOC.md`.

It lists its direct children only, each with a link and a short purpose. Never a deeper level.

It holds the order. A name never does.

A MOC is written and maintained. It is never an automatic inventory.

## Numbers mark places, names mark things

An area folder takes `0010` to `0090`. A subject folder inside takes `N1` to `N9`, once.

`0010-playbook` holds `0011` to `0019`.

No file carries a number. No folder below a subject carries one.

A name says its subject, in kebab-case. It is unique in the vault. A link names a file alone.

A name never says where it sits. A move edits `Up:` and two MOCs. No link breaks.

`0010-playbook/0013-thinking/thinking-protocols/behaviour-protocols/the-behaviour-axioms.md` is one.

A folder's documents of one kind stay together, under headings, until its MOC passes nine children. Only then do they split into subfolders. A new kind of document opens its own folder, whatever the count.

## A document's structure

Line one is the title: `# <Name>`.
Line two is blank.
Line three is `Up:`, linking the parent MOC by filename alone.
Line four is blank.
Line five is one purpose line.
The body follows.

## Every document has one subject

Either a thing, or the way we work. The subject sets the voice.

## What code decides stays in the code

What code decides is never written here: a default, a place, an order, a count. It moves with the code.

A ruled one stays out too. Once built, the code holds it.

A rule for a whole kind keeps its principle, never the value the code holds.

- ❌ "The rail holds Home, Settings and Members, then a line."
- ✅ "A list that exports puts Export last in its bar."

## A document about a thing states what is

A port, a folder, a layer, a site, a machine, a vendor.

Every sentence describes the world. None commands the reader.

It holds whether or not anyone reads it.

State the fact that makes an instruction unnecessary.

- ❌ "An archive is frozen. Never edit one."
- ✅ "An archive is frozen. It records what one trial believed."

Every numbered folder outside the playbook holds this kind.

## A document about the way we work states what to do

How a session talks to me. How a port is taken. How a skill is written.

It exists to be followed, so it may command the reader.

It may also state the fact that makes an instruction unnecessary.

- ✅ "A session binds its derived port, and no other."
- ✅ "Name the subject, never the category."

`0010-playbook/` holds this kind, and only this kind.

Its own purpose line says so: how the work is run.

## A glossary explains our words

A document explaining what our words mean is a glossary.

Its filename ends in `-glossary`. Its title ends in "Glossary".

It holds one closed subject. Its filename names that subject.
