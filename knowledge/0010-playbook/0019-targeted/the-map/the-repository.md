Up: [[the-map-MOC|The Map]]

Which `code/` folder holds which layer, and where sessions meet.

## One repository, one work branch

A file changing under you is normal, not a fault.

## One folder per layer

Every layer has one folder under `code/`.

The folder name matches the layer, without its number.

> **Stand-in.** This project's folders under `code/`: each one, and the layer it holds, if any.

## Where two sessions meet

The same lines of one file.

Lines added beside another's never clash. Edit refuses a file changed since it was read.

One number both take, like a migration's.

One run both need. Every docs server reads one build.

A package's gate reads every file in the package.

Two writers meet at each gate run and walk, never between.

`knowledge/`, `code/tokens/`, the root workspace files, the lockfile.

A shared part, folder or topic is where to look. It is no meeting.
