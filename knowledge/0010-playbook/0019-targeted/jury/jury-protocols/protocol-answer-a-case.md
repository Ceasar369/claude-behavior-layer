# Protocol — Answer A Case

Up: [[jury-protocols-MOC|Jury Protocols]]

When the answer is a case: should I do this, argued both ways.

## The parts it touches

`.claude/tools/jury.py`: the For and Against sessions, the lenses, and the lines an advocate answers in.

[[the-jury-axioms|The Jury Axioms]] hold the floor.

## What a juror gets and returns

An advocate gets the context, the question, its side and one lens. Never my leaning.

It returns its one strongest point, naming the fact it rests on, with its quote and place.

## The questions, in order

1. What is the decision? One question, asked neutrally.
2. Which lenses? My five axes, from [[the-thinking-axioms|The Thinking Axioms]], unless I name others.
3. Is every fact checked? Each runs as a claim, as [[protocol-answer-one-pick|Answer One Pick]] rules.
4. What comes back? Both sides, each fact marked. No count, no recommendation.
