# A Screen's Own List

Up: [[the-screen-MOC|The Screen]]

How a screen holding several pages keeps them apart, and lists them itself.

Where sections stand apart, as Settings' do, a screen never stacks them
down one page.

A screen holding several pages lists them itself, as Settings does.

From `mid`, it stands beside the page. Below, it is its own screen. The
row reaching it is each page's way back. With none, each page carries its
own.

A page under one of its pages carries its own
way back below `mid`.

On a page a screen lists itself, a press that ends what the page shows
sits last, below the page's own press.
