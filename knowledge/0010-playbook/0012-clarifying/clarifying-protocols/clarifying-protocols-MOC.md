# clarifying-protocols — MOC

Up: [[clarifying-MOC|Clarifying]]

Every clarifying protocol, by the kind of exchange it serves.

A clarifying protocol is a written way to clarify one kind of exchange with me.

## Children

- [[protocol-a-purpose-i-state|A Purpose I State]] — an exchange turning a purpose I state into a design.
- [[protocol-what-a-person-sees|What A Person Sees]] — an exchange deciding what a person sees.
- [[protocol-what-a-document-makes-clear|What A Document Makes Clear]] — an exchange agreeing what one document makes clear, before it is written.
- [[protocol-an-explanation-document|An Explanation Document]] — an exchange explaining one subject to me, in one document.

## Admission rule

A protocol enters here when I agree to it.

Every line opens with the kind of exchange it serves.
