# Protocol — Skill Fold

Up: [[skills-protocols-MOC|Skills Protocols]]

When the subject is a skill to fold into the thinker family.

## The parts it touches

Behaviour. A fold edits a skill, its tool and the protocols.

[[the-behaviour-axioms|The Behaviour Axioms]] hold the floor.

## The questions, in order

1. What does the skill do today? Read it, and its tool.
2. Does a sibling protocol already serve its kind? Read every protocol line, and name the overlap.
3. What does its tool do on real data? Run it, and measure.
4. Which of its rules lose their home? Each lands in a question, a lesson, or a file that already says it.
5. Which lines still name it? Search its name across `.claude/` and `knowledge/`.

## The lessons

- Read the raw record when the prose looks wrong.
- Test against a copy of any state the tool writes.
