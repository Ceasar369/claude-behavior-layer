## The questions, in order

1. Which family first? One family at a time, the root first.
2. What does each file do today? Read it, and run it.
3. Which axiom does each breach break? Name it.
4. What does it cost? Words at boot, turns, seconds. Measured, never guessed.
5. What is left? Each finding is an item. One that needs nothing says so.
