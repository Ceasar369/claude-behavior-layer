# Protocol — New Protocol

Up: [[thinking-protocols-MOC|Protocols]]

When the subject is a new thinking protocol to create.

## The parts it touches

Behaviour. A protocol is one vault document under `knowledge/0010-playbook/0013-thinking/thinking-protocols/`.

## The questions, in order

1. Which kind of subject does it serve? That becomes its purpose line, opening "When the subject is".
2. Which thinking parts does that kind usually touch?
3. Which questions does that kind answer, and in what order?
4. What did the thinking that produced it teach? Those are its first lessons.
5. Where does it sit? In the deepest folder whose line matches its kind. A session subject sits in `behaviour-protocols/sessions-protocols/`.

## The lessons

- A protocol has three sections, and no others: the parts, the questions, the lessons.
- A protocol points to a document, like `the-lenses.md`. It never copies it.
- A purpose line opens with the kind of subject. The router matches on those first words.
- A protocol is born when no protocol matched.
- A lesson enters only when I agree to it.
- A lesson is what a failure taught. A choice no failure taught is no lesson. Neither is a line already ruled.
- A fact is no lesson. A tool fact goes to [[the-tools|The Tools]]. A map fact goes to [[the-map-MOC|The Map]].
