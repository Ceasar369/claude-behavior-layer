# Protocol — Full

Up: [[prototyping-protocols-MOC|Protocols]]

When I name Full: locking a screen in.

## The generation

One variation per unknown, or as many as I ask.

One agent writes each, briefed as `prototype-generation` says.

Each is checked at every width I asked for. An error → one agent fixes that variation, then it is checked again.

## The lessons

- Before the first generation, Full alone asks: the unknowns my words name, each one question. Nothing is built before I confirm them.
