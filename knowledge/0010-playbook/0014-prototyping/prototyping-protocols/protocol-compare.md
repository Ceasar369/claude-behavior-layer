# Protocol — Compare

Up: [[prototyping-protocols-MOC|Protocols]]

When I name Compare: choosing a direction among a few.

## The generation

Two or three variations.

One agent writes each, briefed as `prototype-generation` says.

Each is checked at every width I asked for. An error is named in chat, with its variation.

## The lessons

- Before the first generation, nothing is asked. The session builds each direction from my words.
