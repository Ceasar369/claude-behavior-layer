# 2 — Clarify

One door to every clarify shape. This writes no answer of its own.

Only this router combines them. A clarify skill never calls another.

## Step 1 — Read the clarifying folder

Read `knowledge/0010-playbook/0012-clarifying/clarifying-MOC.md` and `knowledge/0010-playbook/0012-clarifying/the-clarifying-axioms.md`.

The axioms hold for the shape this turn calls.

Read `knowledge/0010-playbook/0012-clarifying/clarifying-protocols/clarifying-protocols-MOC.md`.

A line matching this exchange → read that protocol, and follow it.

## Step 2 — Read what I asked for

Whether you understood my message → `clarify-understood`.

I'm lost in the work → `clarify-full-picture`.

Where we stand → `clarify-summary`.

Every item I accepted in a session's waves, recapped → `clarify-recap-items`.

A thing to understand → `clarify-explain`.

A set of things to decide → `clarify-items`.

What happens next, and in what order → `clarify-steps`.

Whether I may take an action now → `clarify-green-light`.

Call the one shape that answers my ask. The rest wait for it.

One subject per turn. The rest wait, in order.

Unclear → `clarify-explain`. A subject is the cheaper miss.

## Step 3 — Call it

My ask needs more than one → the first of: understood, full picture, summary, recap, explain, items, steps, green light.

Name it, in one line. Then invoke it with the `Skill` tool.

The rest follow my answer, one per turn. My next message rules → carry that ruling first. Then invoke `2-clarify` again with the `Skill` tool, on the rest of my ask. Never only name it.

## Never

Never write the answer here.

Never call two in a turn.
