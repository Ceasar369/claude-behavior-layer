# Clarify Explain

One subject per turn. The rest wait, in order.

## Step 1 — Ground it

Read every file the subject touches before writing about it.

Never state a fact from memory.

## Step 2 — Follow the shape

`.claude/rules/talking.md` rules it,
under "Defining a named thing".

A concrete term takes one line instead of three moves.

## Step 3 — Define before using

A name I have not been given is defined where it first appears.

## Step 4 — Stop

Nothing left to ask means saying so, in one line.

## Never

Never open a new decision here. That is `clarify-items`.

Never hand back a menu in place of a position.
